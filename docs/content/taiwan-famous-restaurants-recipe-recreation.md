## 專區定位與法律合規原則（策略 B）

| 項目 | 說明 |
| --- | --- |
| 專區名稱 | 風味主題專區（名店還原） |
| URL | `/restaurant-replicas/` |
| 與其他專區差異 | 早午餐／牛肉等專區偏家常快煮；本專區以**還原經典餐廳代表菜工序與味型**為目標 |
| 份量 | 依實際上桌份量撰寫（常見 2～4 人份或全份） |
| 時間 | 不刻意壓在 10 分鐘；長時間燉煮、分次處理如實記錄 |
| 標籤 | 食譜 frontmatter 需含 `tags: ["名店還原"]` |

### 核心合規原則（策略 B：低調隱晦、零商標侵權風險）

1. **標題與 URL 零商標**：
   - 標題一律使用**經典菜色名稱**（例如「老台北黃金排骨酥」、「酒家菜經典厚煎菜脯蛋」、「阿嬤古早味鳳梨苦瓜雞湯」）。
   - 絕不在 `<h1>` 標題、SEO `<title>`、URL slug 或卡片標題中使用他人註冊之餐廳商標。
2. **內文僅作風格靈感描述**：
   - 僅在 intro 或技巧要點中作輕微的風味靈感帶過（例如「外皮金黃酥脆、蒜香濃郁，口感與天母知名排骨酥名店相似...」）。
   - 清楚表明為家庭烹飪探索與火候技巧拆解，不暗示任何官方授權或背書，徹底杜絕消費者混淆。
3. **味型與工序嚴謹**：
   - 醬油色、酒香、麻油香、湯頭層次等，分次爆香、先煎後燉、冰鎮回軟等關鍵步驟如實呈現。
4. **食材採買如實建議**：
   - 使用的特殊食材（樹子、破布子、老菜脯、土魠魚等）標註家用採買建議與替代方案。
5. **與家常食譜分開**：
   - 同一道菜若站內已有簡化版（如三杯雞蓋飯），名店還原版另開新 slug，並在 intro 說明工序差異。

## 食譜 frontmatter 規範

```yaml
tags:
  - "名店還原"
  - "台菜"          # 或 小吃、海鮮、早午餐 等
category: "台菜"
# 注意：不填寫含商標之 restaurantSource，或僅使用通用風格描述
```

- `category` 建議用：`台菜`、`小吃`、`海鮮`、`湯品`、`麵食`、`美式早午餐` 等。
- `scenarios` 可留空或選與還原無關的情境；**不要**為了進其他專區而加「10 分鐘料理」等標籤。

## 還原難度定義

| 等級 | 說明 | 還原策略 |
| --- | --- | --- |
| ★ 易 | 單鍋小炒、食材易得 | 可先做第一批上線 |
| ★★ 中 | 需分次處理、特殊醬料或湯頭 | 第二優先 |
| ★★★ 難 | 宴席、長燉、手工麵點、高價海鮮 | 長期目標，步驟需分段說明 |
