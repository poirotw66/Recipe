# 首頁晚餐決策板

日期：2026-11-06

## 現況與改動

改動前先在瀏覽器檢視首頁：第一屏以食材輸入和情境分類為主，食譜照片及具體料理選擇需要繼續往下找。

首頁現在把食材搜尋與晚餐提案並列。使用者可選 10／20／30 分鐘上限、換一道，或直接進入食譜。提案使用現有食譜、實際 `totalTime` 與四語內容，優先選主菜和飯麵，避免把一道配菜當成整餐推薦。切換時間優先顯示該時間帶的料理，換菜則循環所有符合上限的候選。

轉換假設：讓沒有明確食材或料理方向的訪客先看到一個可執行的選擇，減少從分類到食譜的決策步驟。主要按鈕沿用 `recipe_card_click` 追蹤；尚未測得實際轉換率變化。

保留品牌、導覽、原有內容與食材搜尋欄位。手機版依序顯示搜尋及提案。推薦內容在伺服器產生，未執行 JavaScript 仍可查看預設食譜；互動控制載入前停用並保留空間。沒有新增套件。
